# Personal website

**Don't open `index.html` in this folder directly.** These are templates that GitHub Pages fills in, so on their own they look unstyled. To see the site on your computer, open `../personal-website-preview/index.html`, or rebuild it first (see "Preview locally").

A plain Jekyll site that GitHub Pages builds for you. No database, no backend, nothing to install unless you want to preview locally.

```
index.html              Home: bio, current projects, recent notes, selected publications
projects/index.html     Projects list (current and past, built automatically)
_projects/*.md          One file per project -> /projects/<file-name>/
publications/index.html Publications page
_data/publications.yml  All publications, talks and reviewing, edited in one place
notes/index.html        Notes (journal) list, grouped by year
_posts/*.md             One file per note -> /notes/<year>/<title>/
_drafts/                Unpublished notes and a template
assets/css/style.css    All styling; colors are the tokens at the top
assets/css/fonts/       One small stylesheet per typeface; _config.yml `font:` picks which one loads
assets/fonts/           The font files themselves (self-hosted, with their licenses)
assets/svg/             All drawings: header waterfall, illustrations, avatar, icon set
_includes/avatar.svg    NV monogram (swap for a photo later, see below)
_includes/waterfall.svg The header mark (regenerate: python tools/make_waterfall.py --seed N)
_includes/illustrations/ Project drawings (regenerate: python tools/make_illustrations.py)
tools/preview.py        Builds a local preview you can open by double-clicking
assets/Vardalakis_CV.pdf  The "CV" link in the menu (phone number removed)
_config.yml             Name, email, links, navigation
```

## Write a note

1. Create `_posts/2026-10-20-my-title.md` (date first, then a short title with hyphens).
2. Start it with:

   ```
   ---
   title: My title
   tags: [paper]
   ---
   ```

3. Write in Markdown below it. Put any images in `assets/img/`.
4. Commit and push (or use "Add file" on github.com directly). The site updates in about a minute, and the note appears on the Notes page, on the home page, and in the RSS feed.

## Add or edit a project

Copy any file in `_projects/`, change the front matter (`title`, `short`, `period`, `place`, `role`, `status`, `current: true/false`, `order`), and write the body. `order` controls the position in lists. Search for `class="todo"` to find the places that still need your input.

## Publish on GitHub Pages (once)

1. On GitHub, create a repository named **NikVard.github.io**.
2. Upload this folder's contents (or `git init`, `git add .`, `git commit`, `git push`).
3. In the repository, go to Settings > Pages, and set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site will be live at https://nikvard.github.io. For a custom domain (e.g. vardalakis.com), add it under Settings > Pages and point your DNS to GitHub.

If you use a different repository name, set `baseurl: /<repo-name>` in `_config.yml`.

## Preview locally

Quick way (Python, works with Anaconda): from this folder run

    python tools/preview.py

then open `personal-website-preview/index.html` (next to this folder) by double-clicking. It is a close approximation of the live site; the live build is the reference.

Exact way: install Ruby, run `bundle install` once and `bundle exec jekyll serve`, then open http://localhost:4000.

## Using a photo later

Save it as `assets/img/portrait.jpg`, then in `index.html` replace `{% include avatar.svg %}` with
`<img class="avatar" src="{{ '/assets/img/portrait.jpg' | relative_url }}" alt="Nikolaos Vardalakis">`.

## Choosing the font

Set `font:` in `_config.yml` to `plex-serif` (default), `eb-garamond` or `newsreader`. The local preview also has a font picker in the bottom-right corner for comparing them; it does not appear on the live site. All three are under the SIL Open Font License: free to use and self-host, no credit needed on the site.
